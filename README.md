# لعبة برا السالفة (نسخة الويب)

تطبيق ويب بسيط للعبة الاجتماعية "برا السالفة" يعمل بدون إنترنت ويخزن البيانات محليًا.

## التشغيل

افتح الملف `index.html` في أي متصفح حديث وستعمل اللعبة محليًا.

## الاختبارات

لتشغيل اختبارات دوال المنطق:

```bash
node tests.js
```

## المجلدات

- `packs/basic.json` : مثال لباقة كلمات.
- `gameLogic.js` : يحتوي الدوال الأساسية للعبة.
- `app.js` : منطق الواجهة وإدارة الحالة.
- `styles.css` : الأنماط الأساسية.

## ملاحظات

هذا الإصدار مبسط ويحتوي على أقل الوظائف لتجربة اللعبة. يمكن تطويره لاحقًا بإضافة مزيد من الشاشات والخصائص.
